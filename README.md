# whoop-mcp — privacy policy

Public hosting for the privacy policy of `whoop-mcp`, a personal, locally-run tool that reads
its operator's own WHOOP data.

Published at <https://app-byte-ai.github.io/whoop-mcp-privacy/> for the privacy policy URL
required when registering an app at developer-dashboard.whoop.com.

This repository contains only the policy page. The tool's source is kept separately.
